# 清蒸鲈鱼动画：人物与接入

组员原件来自用户提供的《买汰烧-单文件版.zip》。采用其场景内字幕、步骤分钟展示、人物按阶段动作的设计，集成到现有清蒸鲈鱼弹窗；未移入整页 Demo 的家庭状态、28 道菜或排菜算法。

用户随后要求人物与蒸锅融合，避免人物自带另一口锅。使用内置 imagegen 分别编辑爸爸和妈妈：保留面容与条纹衣服，移除原图中的锅、桌子、食物、灶台及其他人物，生成伸手操作场景中蒸锅的透明形象。PNG 已验证真实 alpha，直接复制保存，没有重画现有家庭头像。

最终素材：[爸爸](../public/assets/fish-chef-dad.png)、[妈妈](../public/assets/fish-chef-mom.png)。当前动画源码为 [场景参数](../public/steamed-fish-scene.js)、[播放组件](../public/cooking-scene.js)、[动画样式](../public/cooking-scene.css)。

人物置于鱼盘与锅的后层，SVG 在台面处裁去下半身；减少清蒸阶段的整个人物横移，避免穿过锅盖。可切换爸爸/妈妈、重播；关闭弹窗与组件卸载取消播放，减少动态效果时停在成品。通用加载动画保持原来行为。

参考分钟数采用组员单文件版的 3 / 1 / 8 / 3，标注为本菜示例用时约 15 分钟，不作为整桌时间或熟制保证。实际做法和食品规则仍以厨房菜谱、鱼的大小和火力为准。
